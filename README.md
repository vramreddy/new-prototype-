# BankAuctions.ai Prototype

A comprehensive web application prototype for **BankAuctions.ai** — property intelligence platform for bank auction properties across South India (Chennai, Bengaluru, Hyderabad, Coimbatore, Kerala).

## Project Overview

- **Interactive Prototype:** Search and compare residential, commercial, industrial, and agricultural bank auction properties.
- **Key Features:**
  - AI-based property scoring and category ranking
  - On-site verification badges, photographs, and condition reports
  - Independent advocate advisory booking
  - Filter by city, asset class, budget, and auction closing timelines
  - Responsive layout for desktop and mobile devices

## How to Run Locally

### Option 1: Python HTTP Server (Recommended)
```powershell
python -m http.server 8000 --directory prototype
```
Open [http://localhost:8000](http://localhost:8000) in your browser.

### Option 2: Node.js (`npx serve`)
```powershell
npx serve prototype -l 8000
```

### Option 3: Direct Browser Open
Open `prototype/home.html` directly in any web browser.
